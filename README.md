# Solar Security Automation — rediseño local

Primera portada de cuatro servicios: calentadores solares, paneles solares, aire acondicionado y cámaras de seguridad. Conserva Fraunces/Outfit y utiliza el logo vectorizado naranja.

## Ejecutar

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

Vista local: http://127.0.0.1:5173

```sh
npm run build
```

No hay cambios publicados ni push. Las vistas de servicio usan fragmentos de URL, compatibles con el servidor estático y el botón Atrás. Los enlaces de WhatsApp preparan la consulta; nunca envían mensajes automáticamente.

Consultar ASSETS.md para la procedencia de las imágenes.
